Kruti Dev Font: Complete Guide for Marathi

Complete Kruti Dev font guide for Marathi — free download, keyboard layout chart, popular variants (010 011 016 020 055), and Unicode conversion tool.

7 min read·2026-02-10

Kruti Dev is the most widely used legacy font in Marathi and Hindi DTP. This guide covers everything — download, install, keyboard layout, and conversion to Unicode.

What Is Kruti Dev?

Kruti Dev is a family of fonts developed in the 1990s for Devanagari script on early Windows systems. Unlike modern Unicode fonts, it uses a custom encoding — Devanagari-looking glyphs mapped to Latin keyboard positions. This means text only looks correct when Kruti Dev is installed and applied.

Important: Kruti Dev text is NOT real Unicode. It cannot be indexed by Google, cannot be copy-pasted correctly across devices, and does not work on the web or modern apps. For new projects, always use Unicode Devanagari fonts.

Where Kruti Dev Came From, and Why It Stuck Around

Kruti Dev was created in the mid-1990s, well before Unicode support for Indian scripts was reliable on Windows. Government offices, newspapers, and DTP (desktop publishing) studios across Maharashtra and North India adopted it because, at the time, it was one of the only fonts that reliably rendered Devanagari at all. Typists trained on typewriter-style Devanagari layouts (commonly called the "Remington" or "Kruti Dev" layout) for decades, and that muscle memory is exactly why the font never fully disappeared even after Unicode became the modern standard — an entire generation of government typists, court stenographers, and old-school DTP operators still type in this layout every single day.

That history is also why so much of India's older official Marathi and Hindi documentation — court records, old government notices, historic newspaper archives, and legacy DTP files — exists only in Kruti Dev encoding. Anyone who needs to digitise, search, or reuse that text today runs into the same wall: Kruti Dev text looks fine when opened in the exact right font, but is functionally garbage — random Latin characters — to a search engine, a screen reader, or any modern app that doesn't have that specific font installed.

How to Install Kruti Dev on Your Device

If you specifically need to type in the Kruti Dev layout (for example, to match an existing legacy document), here's the general process. Download the font file only from a reputable source — many low-quality "font download" sites bundle unrelated software with the installer, so stick to established typography sites or your organisation's IT-approved source.

  1. Windows: Right-click the downloaded .ttf file and choose "Install" or "Install for all users." Restart any open applications so they detect the new font.
  2. Mac: Double-click the .ttf file and click "Install Font" in Font Book.
  3. Typing: Kruti Dev uses a fixed key-to-glyph mapping rather than a phonetic layout, so typing accurately requires practising the specific key chart or using a Kruti Dev-labelled keyboard overlay.

Kruti Dev vs. Unicode — What Actually Breaks

It's worth being specific about what goes wrong when Kruti Dev text ends up somewhere it shouldn't. Paste Kruti Dev-encoded text into a Google Doc, a website, or a WhatsApp message without the exact font applied, and you won't see Marathi at all — you'll see a jumble of English letters and symbols, because the underlying character codes are just ordinary Latin ones wearing a Devanagari costume. Search engines index the literal underlying characters, not what they visually display as, so Kruti Dev content is invisible to Google search no matter how much real Marathi text it represents. This also breaks copy-paste, screen readers for accessibility, spell-check, and text-to-speech — none of these tools understand the disguise.

Unicode Devanagari fixes all of this by storing the actual Marathi character, not a look-alike substitute. It is the only format that's genuinely portable across operating systems, devices, and applications without requiring a specific font to be pre-installed, which is why every modern platform — from Android keyboards to Microsoft Word to web browsers — has standardised on it.

Frequently Asked Questions

Is Kruti Dev free to download and use?

Kruti Dev is widely distributed as freeware, though licensing terms vary by source. For any new commercial project, we'd still recommend switching to a Unicode font — it avoids licensing ambiguity entirely and works everywhere without extra steps.

Can I convert Unicode Marathi back into Kruti Dev?

Yes, the reverse conversion is technically possible and some tools offer it, though it's rarely needed today — the only real use case is producing a file for an old system that still expects the legacy encoding.

Why does my Kruti Dev text show random English letters on my phone?

Because your phone doesn't have the Kruti Dev font installed and applied to that specific text. Since Kruti Dev isn't Unicode, the device has no way to know it should display Devanagari — it just renders the literal Latin characters stored underneath.
