How to Install Marathi Fonts in MS Word

Step-by-step guide to installing Marathi fonts in Microsoft Word on Windows and Mac. Includes the best fonts per document type and troubleshooting tips.

6 min read·2026-02-15

Microsoft Word supports Devanagari fonts natively. You simply need to install the font on your system first — once installed, it appears in Word immediately.

Step 1 — Download the Font

Option A — From MarathiFontStyle
  1. Go to our Font Generator
  2. Type any text to preview fonts
  3. Click ↓ Font on any card
  4. Opens Google Fonts download page
Option B — From Google Fonts
  1. Go to fonts.google.com
  2. Search for the font name
  3. Click "Download Family"
  4. Extract ZIP to get .ttf files

Step 2 — Install on Windows

  1. Open File Explorer and find the downloaded .ttf file.
  2. Right-click the font file and select "Install" or "Install for all users".
  3. Restart Microsoft Word if it was open.
  4. Search for the font name in Word's font box.

Step 3 — Install on Mac

  1. Double-click the downloaded .ttf file.
  2. Font Book opens with a preview.
  3. Click "Install Font" — immediately available in all apps.

Step 4 — Enable Marathi Typing

Windows:

  1. Settings → Time & Language → Language → Add "Marathi"
  2. Add Marathi Phonetic keyboard
  3. Switch with Win + Space

Mac:

  1. System Preferences → Keyboard → Input Sources → click +
  2. Add Marathi Transliteration
  3. Switch with Control + Space

Formatting Marathi Text Correctly in Word

Beyond installing the right font, a few Word-specific formatting habits make Marathi documents look more polished. Line spacing set to at least 1.15 or 1.5 gives Devanagari's vowel marks and conjunct clusters room to breathe — Marathi text set at single spacing can look visually cramped compared to the same setting for English text, since Devanagari characters carry more vertical detail. For official letters and reports, left alignment generally reads more evenly than full justification, as discussed above. And when combining Marathi and English in the same document, a slightly larger font size for Marathi (by 1-2 points) often helps visually balance the two scripts, since Devanagari characters can appear marginally smaller than Latin characters at the same nominal point size.

Common Problems and How to Fix Them

Even after installing a Devanagari font correctly, a few issues trip people up regularly. Here's how to resolve the ones we hear about most often.

The font shows up as boxes or question marks

This almost always means the font installed but Word hasn't been restarted, or the text is still set to a non-Devanagari font like Arial or Times New Roman even though you typed Marathi characters into it. Select the Marathi text specifically and reapply the font from the font dropdown — Word doesn't always auto-detect script changes within a paragraph.

Conjunct letters (जोडाक्षरे) look broken or disconnected

This is a font-quality issue, not a Word setting. Older or poorly converted Devanagari fonts don't include proper conjunct glyphs, so complex letter combinations fall apart into separate pieces instead of joining correctly. Switching to one of the fonts in the table above — all professionally built with full conjunct support — solves this immediately.

Marathi text runs the wrong direction or spacing looks uneven

Devanagari is left-to-right just like English, so direction issues are rare, but justified paragraph alignment can occasionally produce uneven spacing with Devanagari text since Word's justification engine was primarily tuned for Latin scripts. Switching to left-aligned text usually fixes this for formal letters and reports.

Using Marathi Fonts in PowerPoint and Excel

The same installed font works automatically across the entire Microsoft Office suite — Word, PowerPoint, and Excel all pull from the same system font list, so there's no separate installation step needed. For PowerPoint specifically, stick to bolder display fonts like Baloo 2 or Modak for slide titles, since thin serif fonts can lose legibility when projected on a screen from a distance. In Excel, plain sans-serif fonts like Noto Sans Devanagari or Hind keep tabular Marathi data easy to scan at smaller cell sizes.

Sharing Documents with People Who Don't Have the Font Installed

One detail that catches people out: if you send a Word document with a Marathi font to someone whose computer doesn't have that font installed, Word will silently substitute a different font for display — the text itself stays correct (because it's Unicode), but the visual styling will look different, or occasionally break conjuncts if the substitute font has weaker Devanagari support. Two ways around this: either export the final document as a PDF (which embeds the font and locks the appearance), or use Word's "Embed fonts in the file" option under File → Options → Save before sharing the original .docx.

Frequently Asked Questions

Do I need to buy a Marathi font to use it in Word?

No — every font recommended on this site is free from Google Fonts under an open license that permits both personal and commercial use in Word documents, with no purchase or attribution required.

Why does my Marathi font work in Word but not in WhatsApp or my browser?

As long as the font is Unicode Devanagari (which all fonts here are), the underlying text is portable and will display correctly anywhere — the visual font styling may default to whatever Devanagari font that app uses internally, but the actual Marathi characters will always be correct and readable.

Can I set a Marathi font as my default in Word permanently?

Yes — open the Font dialog (Ctrl+D), select your preferred Marathi font and size, then click "Set As Default" and choose "All documents based on the Normal template" so every new document opens with it pre-selected.
