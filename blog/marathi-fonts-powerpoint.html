How to Use Marathi Fonts in PowerPoint Presentations

Installing Devanagari fonts, typing Marathi text, and designing slides that don't break when you share them.

8 min read·2026-05-18

Marathi-language presentations show up everywhere from school projects to corporate training decks to community event pitches, and PowerPoint handles Devanagari text perfectly well once it's set up correctly. The friction usually isn't PowerPoint itself — it's font installation, typing method, and the classic problem of a presentation looking perfect on your laptop and completely different on the podium computer at the actual event. This guide covers all three.

Step 1 — Install a Marathi Font on Your System

PowerPoint uses whatever fonts are installed at the operating system level — there's no separate "PowerPoint font" concept. Download a Unicode Devanagari font (Noto Sans Devanagari and Hind are dependable defaults for presentations specifically, thanks to their clarity at projector distance), then:

  1. Windows: Right-click the downloaded .ttf file and choose "Install" or "Install for all users." Restart PowerPoint if it was already open.
  2. Mac: Double-click the .ttf file, then click "Install Font" in Font Book that opens automatically.

Once installed, the font appears in PowerPoint's font dropdown immediately, exactly like any English font.

Step 2 — Set Up Marathi Typing

If you're typing Marathi directly rather than pasting pre-written text, you'll need a Marathi input method enabled at the system level:

  • Windows: Settings → Time & Language → Language → Add a language → "Marathi" → enable the Marathi Phonetic keyboard. Switch between languages with Win + Space.
  • Mac: System Preferences → Keyboard → Input Sources → click the + button → add "Marathi" → choose the Transliteration input method. Switch with Control + Space.
  • Alternative: Type in plain English using our Unicode Converter, then copy-paste the resulting Marathi text into your slides — often faster if you're not used to the phonetic keyboard layout.

Choosing the Right Font for Presentation Slides Specifically

Presentation typography has a different set of priorities from print or web design — slides get viewed from a distance, often on a projector with imperfect color and brightness, sometimes by an audience with a range of eyesight. A few guidelines that consistently work:

  • Body text and bullet points: plain, high-legibility sans-serif — Noto Sans Devanagari or Hind, never below roughly 24pt on the actual slide.
  • Slide titles and headings: a bolder display font like Baloo 2 draws the eye and separates the heading from body content at a glance, even from the back of a room.
  • Avoid thin, delicate, or heavily decorative fonts for anything meant to be read from a distance — calligraphy and script fonts that look elegant on a laptop screen often become unreadable once projected.

The "It Looked Fine on My Laptop" Problem

This is the single most common Marathi PowerPoint issue: you build a beautiful deck at home, then arrive at the venue to find the podium computer doesn't have your chosen font installed, and PowerPoint has silently substituted a different font — sometimes breaking Marathi conjunct letters into a disconnected mess in the process, since not every substitute font has full Devanagari support. Two reliable fixes:

  1. Embed the font in the file. Go to File → Options → Save, check "Embed fonts in the file," and save. This packages the font data directly into the .pptx file, so it displays correctly even on a computer that doesn't have the font installed — though this only works reliably within PowerPoint itself, not universally across every viewer.
  2. Export a PDF backup. Before any important presentation, also export a PDF version. PDFs lock in the exact visual appearance regardless of installed fonts, so it's a dependable fallback if the venue computer has font trouble.
  3. Bring the font file itself. If you're presenting from a USB drive on someone else's computer, include the .ttf font file alongside your slides and install it on arrival if needed — it takes under a minute.

Designing Bilingual Marathi–English Slides

Many presentations mix Marathi and English on the same slide — a Marathi heading with English supporting data, for instance. Keep both scripts at a visually matched weight, and avoid placing a very ornate Marathi font directly next to a plain English font, since the contrast in styling can look accidental rather than intentional. A clean sans-serif pairing (Hind or Noto Sans Devanagari alongside a similar-weight English sans-serif like Inter or Roboto) keeps bilingual slides feeling cohesive.

Frequently Asked Questions

Why does my Marathi text show boxes or missing characters in PowerPoint?

This usually means the font isn't actually installed, or the selected text box is still set to a non- Devanagari font like Calibri or Arial even though Marathi characters were typed into it. Select the text and explicitly reapply a Devanagari font from the dropdown.

Can I embed a Marathi font so my presentation looks right on any computer?

Yes — enable "Embed fonts in the file" under File → Options → Save before saving your final .pptx. This significantly reduces (though doesn't 100% eliminate across every possible viewer) font-related display issues on other computers.

Can I use a Marathi font in PowerPoint on a Chromebook or tablet?

Font installation works differently across platforms, and some Chromebook and tablet versions of PowerPoint have more limited custom font support than the full desktop app. For presenting from these devices, exporting a PDF backup in advance is especially worthwhile, since it guarantees the visual appearance regardless of what fonts the device has available.

What's the best Marathi font for a formal business presentation?

Noto Sans Devanagari or Hind for body content, paired with a slightly bolder weight of the same family or Baloo 2 for section headings — both stay clean and professional-looking at projector distance.
