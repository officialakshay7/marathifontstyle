Kruti Dev → Unicode Converter

Paste your Kruti Dev encoded Marathi text and convert it to proper Unicode Devanagari instantly. Free, no installation needed.

How to use: Copy text from old Kruti Dev Marathi documents (it will look like Latin letters), paste below, and click Convert.

What This Converter Actually Does

Kruti Dev is a legacy, non-Unicode font system built in the 1990s, before Indian-script Unicode support was reliable on Windows. Instead of storing real Devanagari characters, it remaps Devanagari-looking glyph shapes onto ordinary Latin keyboard keys — so text typed and displayed in Kruti Dev only looks correct on a device that has that exact font installed. Move the same text anywhere else — a website, WhatsApp, a phone without the font — and it reverts to showing the underlying English letters and symbols instead of Marathi.

This tool reverses that problem. It reads the Kruti Dev key mapping character by character and rebuilds the text as genuine Unicode Devanagari — the same character-encoding standard used by every modern website, app, and operating system. Once converted, the output is fully portable: searchable by Google, correct on every device, and safe to paste anywhere without needing a specific font installed.

Where Kruti Dev Text Usually Comes From

Most people land on this tool because they've inherited old content that was created before Unicode became the standard: government notices and forms, court documents and legal records, old newspaper archives, DTP files from local print shops, or a Word document someone typed years ago using the Kruti Dev keyboard layout. Because Kruti Dev was the default for a large share of Devanagari desktop publishing in the 1990s and 2000s — and because a generation of typists trained specifically on its keyboard layout — huge amounts of otherwise valuable Marathi and Hindi text still exist only in this format.

How to Use This Converter

  1. Open the original Kruti Dev document or webpage and select the Marathi text — it will visually appear as readable Devanagari if the Kruti Dev font is installed on that device, or as jumbled English letters if it isn't.
  2. Copy the text and paste it into the input box on this page.
  3. Click Convert to Unicode.
  4. Check the output box — it should now display correct, readable Marathi in standard Unicode.
  5. Click Copy Output and paste the converted text anywhere: a website, a document, a message, or a spreadsheet.

For best results, always copy the text directly from wherever it currently displays correctly in Kruti Dev — don't retype it manually, since even a small typo in the original Latin-character encoding will convert to the wrong Devanagari glyph.

After Conversion — Keep Working in Unicode

Once you've converted a document, there's rarely a good reason to go back to the legacy format. Continue any further editing, formatting, or reuse of that content in Unicode from this point on, and if you're setting up a new Marathi document from scratch, skip Kruti Dev entirely and type directly in Unicode using our Unicode transliteration converter or a system-level Marathi phonetic keyboard. This avoids ever having to run this exact conversion again for new content.

Tips for Cleaner Conversion Results

  • Copy from source, don't retype. Manually retyping Kruti Dev text introduces the risk of keying in the wrong Latin character for a glyph you're only reading visually, which then converts to the wrong Devanagari letter. Always copy-paste directly from the original file or webpage.
  • Convert in smaller chunks for very long documents. If you're working with a multi-page legal or archival document, converting a section at a time makes it much easier to spot and fix anything that looks off before moving to the next section.
  • Check conjunct-heavy words first. Complex Marathi conjunct consonants (जोडाक्षरे) are the most likely spot for a subtle conversion mismatch — scan names, legal terms, and technical vocabulary specifically before trusting the full output.
  • Keep the original file as a backup. Even after a successful conversion, hold onto the original Kruti Dev version until you've fully verified the Unicode output, especially for legal, government, or historically significant documents.

Frequently Asked Questions

Why does my Kruti Dev text look like random English letters before converting?

Because Kruti Dev isn't Unicode — it substitutes Devanagari-looking shapes for ordinary Latin keyboard characters, and only displays correctly when the exact Kruti Dev font is applied. Without that font, you're seeing the literal underlying English characters, which is exactly what this tool reads and converts.

Is this conversion 100% accurate for every document?

It handles the standard Kruti Dev character mapping accurately for the vast majority of text. Documents using unusual formatting, mixed fonts within the same paragraph, or non-standard Kruti Dev variants may need a quick manual check afterward, which is generally good practice for any converted legal or formal document regardless.

Can I convert Shree Lipi or DevLys text with this tool?

No — Shree Lipi and DevLys use different internal key-to-glyph mappings from Kruti Dev, so this converter, built specifically for Kruti Dev's mapping, won't produce correct results on those formats. See our guide on Unicode vs. Kruti Dev vs. Shree Lipi for more on the differences, or our DevLys conversion guide for that specific format.

Is my pasted text stored anywhere?

No — the conversion runs entirely in your browser. Nothing you paste is uploaded, stored, or logged on any server, so it's safe to use even for sensitive or confidential legacy documents.
